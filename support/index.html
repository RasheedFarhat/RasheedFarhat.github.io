How I work a queue

Four habits.

Own it through resolution

A first response is not a fix. I confirm it actually worked before I close anything.

Escalate with the diagnosis

What I tried, what I ruled out, how to reproduce it. Never just the original symptom.

Translate both directions

Turn "it stopped working" into something specific, then explain the cause back in plain language.

Fix the pattern

Forty people asking the same thing is a documentation problem wearing a support costume.
