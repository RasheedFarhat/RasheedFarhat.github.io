About

I build detection systems that show their work.

I'm Rasheed Farhat. I work in detection engineering and security operations, from Rochester, Minnesota. My work sits where detection logic, software behavior, evidence quality, and operational constraints meet.

How I work

Build the mechanism. Test the claim. State the limit.

Systems over demos

A detection is one part of a control. I build the inputs, validation, approval, and failure handling around it, then document them so another engineer can follow the path. Control Plane exists because the handoffs between those parts are where operations actually break.

Measured claims

I prefer a bounded, reproducible result to a broad one. Corpus limits and evasion gaps are published next to the numbers they qualify.

My code gets reviewed too

The identity deception case study lists its own webhook authentication and source-attribution gaps. Finding those is part of the work, not a footnote.

Write it down

Every project ships with the trace, the threat model, or the report another person needs to verify or challenge the result.
