Method

What tested and bounded actually costs.

4 rules / applied to every system below

  • Corpus

    A claim gets a corpus, not an example.

    Ten MCP detection rules were not called working until they ran clean across 4,727 benign records and 541 sessions. A single demo capture proves the plumbing works, not that the rule stays quiet.

  • Boundary

    The limit ships with the result.

    Three of twelve documented evasion classes have no signature I can write against them. That count sits on the project page beside the detections it qualifies, not in a footnote underneath them.

  • Retraction

    A wrong claim gets retracted, not quietly edited.

    Assertion Desk’s own limitations file claimed one adversarial payload had a real path into a model prompt. Reading the code found a second path the file never accounted for. The corpus grew from four cases to nine, and I published the correction instead of editing the file quietly.

  • Assurance

    Silence is not verification.

    The MCP review framework records control state on a six-value model where an absence of telemetry indicators can never return verified. Nothing alarmed is a fact about the sensors, not about the control.
