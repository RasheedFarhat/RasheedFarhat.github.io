4 rules / applied to every system above

  • Corpus

    4,727 benign records before a rule counts as working.

    Ten MCP detection rules ran clean across that corpus and its 541 sessions first. A single demo capture only shows that the rule fires on the attack it was written for.

  • Boundary

    Three of twelve evasion classes have no signature I can write.

    That count sits on the project page in the same list as the detections it qualifies, where a reader meets it while deciding what the rules are worth.

  • Retraction

    The correction got its own headline.

    Assertion Desk’s own limitations file claimed one adversarial payload had a real path into a model prompt. Reading the code found a second path the file never accounted for. The corpus grew from four cases to nine, and the correction runs as its own article.

  • Assurance

    An absence of indicators never returns verified.

    The MCP review framework records control state on a six-value model, and verified is reachable only through a test that ran. Nothing alarmed gets a value of its own there, because it reports on the sensors and not on the control.
